# Mustertest — vollständige Prüfliste

Zum Ausdrucken oder am Bildschirm abarbeiten. Jede Zeile prüft eine Angabe, für die
du als Verkäufer haftest, oder eine Eigenschaft, die über den Preis entscheidet.

**Die Spalte „Soll" ist das, was Seite, Karton oder Lieferant behaupten. Trag daneben
ein, was du misst.**

---

## Block A — Sofort, ohne Hilfsmittel (5 Minuten)

| Prüfung | Soll | Ist | Bedeutung bei Abweichung |
|---|---|---|---|
| Anzahl Kraftstufen durchschalten | **9** | | Technik-Sektion und Anzeigentexte müssen geändert werden |
| Anzahl Aufsätze im Karton | **4** | | Lieferumfang auf der Seite anpassen |
| Aufsatzformen | Kugel, U-Form, Flach, Zylinder | | Die Seite nennt den vierten „Spitz" — Handbuch sagt „Cylindrical" |
| Farbe | **Mattschwarz** | | Alle Produktfotos hängen daran |
| Ladeanschluss | **USB-C** | | Steht jetzt so auf der Seite |
| Gehäuse | ABS-Kunststoff, Silikonaufsätze | | Materialangabe im Datenblatt |
| Griff fest gebogen, nicht steckbar | **fest** | | **Kernargument des Vergleichsabschnitts** |

## Block B — Messen (10 Minuten)

| Prüfung | Soll | Ist | Wie |
|---|---|---|---|
| **Gewicht ohne Zubehör** | **590 g** | | Küchenwaage, Gerät allein, kein Aufsatz, kein Kabel |
| Gewicht mit einem Aufsatz | — | | Für den Fall, dass die 590 g so gemeint waren |
| Gewicht Gesamtpaket | 856 g brutto | | Alles im Karton zusammen |
| **Lautstärke Stufe 1** | ≤ 45 dB | | Schallpegel-App, **50 cm Abstand**, ruhiger Raum |
| **Lautstärke Stufe 9** | ≤ 45 dB | | Vorher Raumpegel ohne Gerät notieren |
| Länge des Geräts | ~34 cm | | Von Griffende bis Kopfmitte |

> Die Amplitude von 7,5 mm lässt sich zu Hause nicht sinnvoll messen. Sie steht auf dem
> Karton und wird als Herstellerangabe behandelt.

## Block C — Zeitmessungen (ein Abend, größtenteils Wartezeit)

| Prüfung | Soll | Ist | Wie |
|---|---|---|---|
| **Ladezeit von leer auf voll** | **2–3 h** | | Startzeit notieren, Ladeanzeige beobachten |
| **Laufzeit Stufe 1** | **30–35 min** | | Voll geladen, Stufe 1, durchlaufen lassen bis es ausgeht |
| Laufzeit Stufe 9 | keine Angabe | | Dieselbe Methode, zweiter Ladezyklus |

Beide Laufzeiten stehen als Behauptung auf der Seite. Weichen sie ab, muss die
Technik-Sektion und der FAQ-Eintrag geändert werden.

## Block D — Belastung und Verarbeitung

Das ist der Teil, der über die Qualität entscheidet — nicht die Datenblätter.

| Prüfung | Worauf achten |
|---|---|
| **Stalltest** | Kopf mit deutlichem Druck gegen ein Kissen oder den Oberschenkel pressen, Stufe 9. **Bleibt der Motor stehen?** Ein Gerät, das unter normalem Druck stehen bleibt, ist im Alltag unbrauchbar |
| **Biegt sich der Bogen?** | Mit Kraft gegen den Kopf drücken. Gibt der gebogene Griff sichtbar nach? Der Vergleichsabschnitt behauptet „der Bogen bleibt, wie er ist" |
| **Sitzt der Aufsatz fest?** | Unter Druck ziehen und drehen. Löst er sich? Fliegt er ab? |
| **Dauerlauf 20–30 min auf Stufe 9** | Gehäuse anfassen: sehr heiß? Riecht es nach Elektronik? Wird das Geräusch rauer? Lässt die Kraft nach? |
| **Spaltmaße und Grat** | Sichtbare Fugen, scharfe Kanten, Klebereste |
| **Bedienung** | Reagieren die Tasten sauber? Springt es zuverlässig an? Merkt es sich die Stufe? |
| **Silikonaufsätze** | Riechen sie stark? Sind sie weich oder hart und billig? |

> **Haltbarkeit lässt sich mit zwei Geräten nicht feststellen.** Der Dauerlauf ist eine
> Näherung: Wer die erste halbe Stunde unter Volllast nicht übersteht, überlebt auch
> kein Jahr. Wer sie übersteht, über den weißt du trotzdem nichts.

## Block G — Pflichtkennzeichnung

Alle vier sind für den Verkauf in Deutschland vorgeschrieben. Auf dem Muster fehlten
sie beim ersten Durchsehen.

| Kennzeichen | Auf Gerät? | Auf Verpackung? | Pflicht aus |
|---|---|---|---|
| **CE-Zeichen** | | | Produktsicherheit |
| **Name und Anschrift des Importeurs** | | | GPSR (EU) 2023/988 |
| **Durchgestrichene Mülltonne** | | | ElektroG |
| **Batteriesymbol** | | | BattG |
| Typenschild mit Spannung und Leistung | | | |

**Wenn eines fehlt, muss es vor dem Verkauf ergänzt werden.** Das CE-Zeichen darf nur
anbringen, wer die Konformität erklären kann — also erst, wenn die Unterlagen vorliegen.

## Block H — Fotos, die du jetzt machen solltest

Nicht für die Prüfung, sondern weil du sie später brauchst.

- [ ] Typenschild am Gerät, scharf und lesbar
- [ ] Gerät auf der Waage, mit ablesbarer Anzeige
- [ ] Alle vier Aufsätze nebeneinander
- [ ] Gerät in der Hand, am eigenen Rücken angesetzt — **das fehlt der Seite am meisten**
- [ ] Karton von allen Seiten
- [ ] Beiliegende Anleitung, alle Seiten

## Was mit den Ergebnissen passiert

| Ergebnis | Folge |
|---|---|
| Alle Angaben stimmen, Gerät wirkt solide | 60 Stück bestellen, Registrierungen laufen lassen |
| Einzelne Zahlen weichen ab | Seite korrigieren, Rest bleibt |
| Motor bleibt unter Druck stehen | **Abbruch.** Ein Massagegerät, das stehenbleibt, verkauft sich einmal und kommt zurück |
| Bogen biegt sich sichtbar | Vergleichsabschnitt streichen — dann bleibt kein Argument |
| Gerät wirkt billig | Preis auf 59–69 € senken oder ganz absehen |

**Nach dem Test steht die Entscheidung über die 60 Stück.** Vorher fließt kein Geld für
Ware — die Registrierungen laufen unabhängig davon weiter, weil sie Wochen brauchen.
